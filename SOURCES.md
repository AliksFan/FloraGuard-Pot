# Reference materials

Low-level development drew on STC8H technical manuals and related peripheral examples. The local manual copies inspected for this project carry update dates of 16 March 2023 and 21 December 2021 and STC micro branding.

The manuals informed register configuration and peripheral handling. Exact file-level attribution and redistribution terms for all referenced examples have not been fully reconstructed. This repository does not claim that every driver or line of code was written from scratch.

The application-level contribution is described in the [README](README.md). Vendor device headers, compiler headers, Keil startup code and hardware design files are not included. No project license has been selected.
